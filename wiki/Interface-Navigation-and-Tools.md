# Interface, Navigation & Tools

HABit is designed for speed, responsiveness, and seamless everyday operation on mobile phones, desktop browsers, and wall-mounted touchscreens.

---

## 🧭 Dual-Action Topbar Navigation

The **HABit Logo and Month Title** in the top navigation bar functions as an intelligent navigation control:

```
[ 🪙 HABit | September 2026 ] ──► Dual-Action Interaction
```

1. **Back / Return to Overview**:
   - When viewing **Settings**, **Scheduled Bills**, **Budgets & Occasions**, or **Annual Trajectory**, clicking the logo acts as an instant **Back button**, returning you to your active month overview.
2. **Current Week Jump & Pulse Focus**:
   - When already viewing the monthly budget, clicking the logo instantly smooth-scrolls and highlights the **Current Week card** with an animated glow pulse (`.week-highlight-pulse`).

---

## 🧮 Floating Financial Calculator (`Alt+C`)

HABit includes a built-in, draggable financial calculator:

```
┌───────────────────────────┐
│ 🧮 Financial Calculator   │
├───────────────────────────┤
│ [  ( 1250 - 450 ) * 0.20 ]│
│ = 160.00                  │
├───────┬───────┬───────┬───┤
│   (   │   )   │   %   │ C │
│   7   │   8   │   9   │ / │
│   4   │   5   │   6   │ * │
│   1   │   2   │   3   │ - │
│   0   │   .   │   =   │ + │
└───────┴───────┴───────┴───┘
```

### Calculator Capabilities:
- **Keyboard Shortcut**: Press `Alt+C` anywhere in the app to toggle the calculator.
- **Mathematical Precedence**: Full bracket `( )`, percentage `%`, and operator order support.
- **Calculation History Tape**: Stores recent calculations with one-click **Copy Result** and **Re-use Expression** buttons.
- **🎯 Interactive Value Picker**: Click the **Value Picker** button, then click any financial number on the screen to inject it directly into your calculation!

## ⚡ Floating Action Button (FAB) Speed Dial

On mobile and desktop, the bottom-right `+` button opens quick actions:
- 💳 **Balance Check-In**: Update checking balances in seconds.
- 🛒 **Add Weekly Expense**: Log an expense against the current week.
- 🎁 **Log Occasion Purchase**: Record a gift or holiday expense.

---

## 🎨 Zero-Flash 4-Theme Engine

HABit features 4 handcrafted themes with zero white-flash on load:
1. 🌑 **Dark Mode Charcoal**: Modern dark slate theme optimized for OLED screens.
2. 🌊 **Navy Dark (Deep Blue)**: Rich navy blue aesthetic.
3. ☀️ **Light Mode**: Crisp, high-clarity daylight theme.
4. ⚡ **High Contrast**: Enhanced contrast theme for accessibility.
